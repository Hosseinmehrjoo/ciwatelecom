کانفیگ میکروتیک برای مرکز تلفن

این صفحه فقط روتر را پوشش می‌دهد. فرض می‌کند CIWA روی سرور داخل شبکه نصب شده است. دستورها را در Terminal میکروتیک بزنید و آدرس‌های نمونه را با شبکه خودتان عوض کنید.

نمونه سرور: 192.168.88.10 نمونه LAN: 192.168.88.0/24 نمونه گیت‌وی: 192.168.88.1 پنل: 8080 یا 3000

۰۲نقشه شبکه نمونه

نقشآدرستوضیح
میکروتیک (گیت‌وی)192.168.88.1DHCP و فایروال اینجا است.
سرور CIWA192.168.88.10آدرس ثابت. از استخر DHCP خارجش کنید یا رزرو بسازید.
گوشی‌ها192.168.88.0/24همان VLAN یا شبکه سرور، مگر جدا کرده باشید.

اگر پنل روی پورت 3000 بالا آمده (نصب توسعه)، در قانون‌های فایروال 3000 را به‌جای 8080 بگذارید. در نصب تولید معمولاً 8080 است.

پورت 5038 فقط برای خود سرور است. برایش در میکروتیک قانون accept نسازید و dst-nat هم نکنید.

۰۴خاموش کردن SIP ALG

اگر این سرویس روشن باشد، زنگ می‌خورد ولی صدا یک‌طرفه یا قطع می‌شود. همیشه اول این را بزنید.

/ip firewall service-port
set sip disabled=yes

وضعیت را با /ip firewall service-port print where name=sip چک کنید. باید Disabled باشد.

۰۵لیست آدرس‌ها

با لیست، قانون‌ها خوانا می‌مانند و وقتی VLAN اضافه می‌کنید فقط یک خط به لیست می‌زنید.

/ip firewall address-list
add list=ciwa-pbx address=192.168.88.10 comment="CIWA server"
add list=ciwa-phones address=192.168.88.0/24 comment="IP phones"
add list=ciwa-admins address=192.168.88.0/24 comment="panel users"
اگر شبکه تلفن جدا است، مثلاً 10.10.20.0/24، همان رنج را به ciwa-phones اضافه کنید. مدیران پنل را می‌توانید به چند IP محدود کنید.

۰۶فایروال برای تماس داخلی

این قانون‌ها را بالاتر از drop عمومی بگذارید. اگر اینترفیس اینترنت در لیست WAN نیست، به‌جای in-interface-list=WAN بنویسید in-interface=ether1.

/ip firewall filter
add chain=forward action=accept connection-state=established,related comment="ciwa established"
add chain=forward action=accept connection-state=new src-address-list=ciwa-phones dst-address-list=ciwa-pbx protocol=udp dst-port=69 comment="ciwa TFTP"
add chain=forward action=accept connection-state=new src-address-list=ciwa-phones dst-address-list=ciwa-pbx protocol=udp dst-port=5060 comment="ciwa SIP"
add chain=forward action=accept connection-state=new src-address-list=ciwa-pbx dst-address-list=ciwa-phones protocol=udp src-port=5060 comment="ciwa SIP reply"
add chain=forward action=accept connection-state=new src-address-list=ciwa-phones dst-address-list=ciwa-pbx protocol=udp dst-port=10000-20000 comment="ciwa RTP to server"
add chain=forward action=accept connection-state=new src-address-list=ciwa-pbx dst-address-list=ciwa-phones protocol=udp src-port=10000-20000 comment="ciwa RTP to phones"
add chain=forward action=accept connection-state=new src-address-list=ciwa-admins dst-address-list=ciwa-pbx protocol=tcp dst-port=8080 comment="ciwa panel"
add chain=forward action=accept connection-state=new src-address-list=ciwa-admins dst-address-list=ciwa-pbx protocol=tcp dst-port=3000 comment="ciwa panel alt"
add chain=forward action=accept connection-state=new src-address-list=ciwa-admins dst-address-list=ciwa-pbx protocol=tcp dst-port=8089 comment="ciwa softphone"
add chain=forward action=drop connection-state=new dst-address-list=ciwa-pbx protocol=udp dst-port=69,5060,10000-20000 in-interface-list=WAN comment="block phone ports from internet"
add chain=forward action=drop connection-state=new dst-address-list=ciwa-pbx protocol=tcp dst-port=3000,8080,8089,8788,5038 in-interface-list=WAN comment="block panel AMI API from internet"
برای مسیر الف هیچ dst-nat نسازید. تماس داخلی نباید از اینترنت رد شود.

۰۷DHCP، آدرس ثابت سرور، گزینه 150 سیسکو

آدرس ثابت برای سرور

یا سرور را از استخر DHCP خارج کنید، یا رزرو بسازید تا IP عوض نشود.

/ip dhcp-server lease
add address=192.168.88.10 mac-address=AA:BB:CC:DD:EE:FF comment="CIWA server" server=defconf

مک سرور و نام DHCP server خودتان را جای نمونه بگذارید. نام سرور را با /ip dhcp-server print ببینید.

گزینه 150 برای Cisco 7942 / 7962

گوشی سیسکو آدرس TFTP را از گزینه 150 می‌گیرد. مقدارش چهار بایت هگز IP سرور است، نه متن.

بعد از ساخت فایل SEP<MAC>.cnf.xml روی سرور، گوشی را یک‌بار ری‌استارت کنید تا TFTP را بخواند.

۰۸خط شهری · dst-nat و hairpin

فقط وقتی ترانک SIP دارید این بخش را اجرا کنید. 1.2.3.4 را با IP عمومی ثابت شرکت و 203.0.113.10 را با IP سرور SIP مخابرات عوض کنید.

فوروارد به سرور

/ip firewall nat
add chain=dstnat action=dst-nat protocol=udp dst-address=1.2.3.4 dst-port=5060 to-addresses=192.168.88.10 to-ports=5060 comment="ciwa SIP"
add chain=dstnat action=dst-nat protocol=udp dst-address=1.2.3.4 dst-port=10000-20000 to-addresses=192.168.88.10 comment="ciwa RTP"

Hairpin برای تماس داخلی وقتی IP خارجی پر است

اگر در پنل فیلد «IP خارجی» پر شده، گوشی‌های داخل شبکه هم صدا را به IP عمومی می‌فرستند. بدون این دو خط، تماس شهری کار می‌کند و تماس داخلی بی‌صدا می‌شود، یا برعکس.

/ip firewall nat
add chain=srcnat action=masquerade protocol=udp src-address=192.168.88.0/24 dst-address=192.168.88.10 dst-port=5060 comment="ciwa hairpin SIP"
add chain=srcnat action=masquerade protocol=udp src-address=192.168.88.0/24 dst-address=192.168.88.10 dst-port=10000-20000 comment="ciwa hairpin RTP"

فقط مخابرات به SIP برسد

/ip firewall filter
add chain=forward action=accept connection-state=new protocol=udp dst-address=192.168.88.10 dst-port=5060 src-address=203.0.113.10 comment="SIP only from provider"
add chain=forward action=accept connection-state=new protocol=udp dst-address=192.168.88.10 dst-port=10000-20000 in-interface-list=WAN comment="RTP from calls"
add chain=forward action=drop connection-state=new protocol=udp dst-address=192.168.88.10 dst-port=5060 in-interface-list=WAN comment="drop other internet SIP"
قانون accept مخصوص فروشنده را بالاتر از drop عمومی SIP بگذارید. پنل، TFTP و AMI را فوروارد نکنید.

۰۹چیزهایی که عمداً باز نمی‌کنیم

  • TCP 5038 به هیچ کجا غیر از خود سرور
  • TCP 8788 از بیرون یا حتی از کل LAN اگر لازم نیست
  • UDP 69 از اینترنت
  • پنل (8080 / 3000) از اینترنت
  • Winbox و SSH روتر از اینترنت بدون محدودیت
باز بودن SIP روی کل اینترنت یعنی حمله و تماس‌های جعلی. اگر خط شهری دارید، منبع را به IP مخابرات محدود کنید.

۱۰آزمون سریع

  1. از یک کامپیوتر داخل شبکه پنل را باز کنید: http://192.168.88.10:8080 یا پورت 3000.
  2. از بیرون شبکه همان آدرس را امتحان کنید؛ نباید باز شود.
  3. دو گوشی را Register کنید و از 101 به 102 زنگ بزنید. صدای دوطرفه لازم است.
  4. اگر سیسکو دارید، در لاگ TFTP سرور درخواست SEP... را ببینید.
  5. از موبایل به DID شرکت زنگ بزنید و یک تماس خروجی با صفر اول بگیرید.

۱۱اگر کار نکرد

نشانهکار بعدی
زنگ هست، صدا نیستSIP ALG خاموش باشد. UDP 10000-20000 در هر دو جهت باز باشد. در مسیر شهری hairpin را چک کنید.
گوشی Register نمی‌شودقانون SIP 5060، IP سرور ثابت، و عدم وجود dst-nat اشتباه برای مسیر داخلی.
سیسکو فایل نمی‌گیردگزینه 150، UDP 69، و روشن بودن سرویس TFTP روی سرور.
پنل از بیرون باز استقانون drop روی WAN برای 8080/3000 را ببینید. ممکن است dst-nat جدا داشته باشید؛ حذفش کنید.
تماس شهری قطع استdst-nat فقط به 192.168.88.10، و accept فقط از IP مخابرات بالاتر از drop.
 
/ip firewall service-port print where name=sip
/ip firewall address-list print where list~"ciwa"
/ip firewall filter print where comment~"ciwa"
/ip firewall nat print where comment~"ciwa"
/ip dhcp-server option print where name=ciwa-tftp
